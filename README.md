# Automated Data Cleaning & Reporting System

## Overview

This project automates the process of data cleaning and report generation using Python and Pandas.

The system reads raw company data from a CSV file, performs preprocessing operations such as handling missing values and removing duplicates, and automatically generates a summary report in Excel format.

This project helps reduce manual effort in data preprocessing and reporting tasks.
